# Homebrew Tap for Etherscan CLI

Homebrew formulae for [Etherscan CLI](https://github.com/etherscan/etherscan-cli).

## Install

```sh
brew install etherscan/etherscan-cli/etherscan
```

## Upgrade

```sh
brew update
brew upgrade etherscan/etherscan-cli/etherscan
```

To keep the currently installed version instead of upgrading it:

```sh
brew pin etherscan
```

See the Etherscan CLI's [full installation guide](https://github.com/etherscan/etherscan-cli#install) for other installation methods, documentation, and usage.
